# Komiyomi

Komiyomi (こみよみ) is the offline CBZ/CBR reader identity. The icon is a custom vector interpretation of the first hiragana character, こ.

- Vermilion: `#B63736`
- Warm cream: `#FFF5E6`
- Wordmark ink: `#282321`

`komiyomi-icon.svg` and `komiyomi-logo.svg` are the scalable source assets. `komiyomi-icon.png` is a 432 px export. Android uses matching vector assets, including an adaptive launcher icon and a monochrome variant for themed icons.

The separate application ID is `app.komiyomi` (`app.komiyomi.dev` for debug), so Komiyomi installs independently from Komikku. Its visible name resolves to the Komiyomi resource in every locale through an app-level resource alias. Upstream strings and translations are preserved.
